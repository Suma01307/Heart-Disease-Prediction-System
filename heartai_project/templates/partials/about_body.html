About HeartAI

HeartAI is an educational Django application that demonstrates how machine learning can support heart-disease risk screening using three kinds of input:

  • Clinical data — the 13 classic Cleveland/UCI features (age, blood pressure, cholesterol, ECG result, …) analysed by a scikit-learn classifier.
  • Chest X-ray images — an image classifier labelling scans as normal or abnormal.
  • ECG images — an image classifier labelling ECG traces as normal or abnormal.

Research purpose

Built for academic and demonstration use. Prediction quality depends entirely on the data the models were trained on.

Data privacy

All data is stored locally in this application's SQLite database and media/ folder. Do not upload real patient-identifiable data to a shared or public deployment.
